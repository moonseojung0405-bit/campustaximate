Unmodified Galmuri 11 Bold font files by quiple, distributed under SIL Open Font License 1.1.

- Source: https://github.com/quiple/galmuri
- Font files: https://github.com/quiple/galmuri/tree/main/dist

The TTF is embedded in the statically generated Open Graph and Twitter images. The WOFF2 can be used for pixel-style headings without relying on a third-party font CDN.
